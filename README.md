# National Communications Subcommittee (NCC) Stakeholder Hub
**Destination URL:** `oa-scouting.org/ncc`  
**Layout Structure:** Multi-tab / Sticky Jump-Nav Hub

A comprehensive, public-facing stakeholder portal serving as the centralized service catalog, timeline SLA reference, policy documentation library, and intake routing hub for the National Communications Subcommittee (NCC) of the Order of the Arrow, Scouting America.

---

## 🌟 Key Features

- **Hero & Mission Statement**: Clear institutional positioning as the strategic marketing and communications partner across the National Order of the Arrow Committee.
- **Sticky Jump Navigation**: Fast jump-links to `[ ✦ Service Offerings ]`, `[ ➔ Timelines & SLAs ]`, `[ ▤ Policies & Standards ]`, and `[ ? Intake & Contact ]` with active scroll-spy indicators.
- **Service Offerings Catalog**: Categorized 5-tier catalog covering Written Content & Copywriting (LOOA compliant), Digital & Social Media, Website Management, Branding & Design, and Analytics & Impact.
- **Timelines & Production SLAs**:
  - Standard Content Production 4-stage pipeline (Ideation, Plan Review, Development, Final Review).
  - High-contrast SLA matrices for website turnarounds (Quick: 48h–1w, Moderate: 2+ weeks, Complex: 2+ months).
  - External content review workflow (Mandatory 3-week cycle across Team Review ➔ Editorial Edits ➔ Leadership Sign-off via Asana).
- **Standards & Policy Governance**:
  - Interactive accordions detailing Youth Protection & contact list compliance (LodgeMaster/NOAERS exports directly to strategists).
  - Generative AI usage rules with clear Permitted vs. Prohibited guidance.
  - Volunteer Board position guidelines (concise roles, omitting internal committee acronyms).
  - Downloadable resource links for LOOA, OA Brand Standards, Quarterly Communication Plan Template, and Creative Brief Forms.
- **Intake & Contact Dual-Path Workflow**:
  - **Path A**: Dedicated partnership routing for subcommittees with assigned Brand Leads (`comms-partner@oa-scouting.org` & `communications@oa-scouting.org`).
  - **Path B**: Direct Jira Service Desk intake portals (requiring ArrowID) for general requests and Volunteer Board revisions.
  - **Interactive SLA Calculator**: Instant estimation tool matching requested deliverables to their production turnarounds.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/austinhttps/oa-ncc-hub.git
cd oa-ncc-hub

# Install dependencies
npm install

# Run the local development server
npm run dev
```

### Production Build
```bash
# Typecheck and bundle for production
npm run build

# Preview production build locally
npm run preview
```
